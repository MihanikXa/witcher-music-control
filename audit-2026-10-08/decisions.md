# Implemented compatibility decisions

This implementation supersedes the first-pass preservation gates in conflicts.md and resolutions.md. The user explicitly delegated qualitative choices. No deployment or game launch was performed. The release targets Steam build **25773555 / executable 5.0.0.1048522**, discovered after Steam updated during this work.

## Quest resources: UPR wins all eight

UPR's coherent quest redesign is selected ahead of BIA for these resources. BIA remains installed for its other fixes. This is a priority resolution, **not a binary merge**. Both versions of every resource have distinct decompressed hashes; the exact hashes/sizes remain in conflicts.md and the private effective-resource-winners.json.

The UPR author specifies UPR-first compatibility. That supports choosing a coherent authored set, but does not prove incorporation of every BIA fix. BIA's detailed public sheet is historical v3.0 evidence, not an exact installed 4.0.3 node diff. No identified change in these eight resources was established to be a critical soft-lock fix; this does not establish that no such fix exists. Critical progression integrity is a release-test gate, not something certified by priority. ## Scripts, localization and operational choices

The five existing merges preserve 13 installed-source contributions. Semantic review found AutoLoot's repeating timer duplicates its interval-aware player tick; the manager now removes that timer, retaining the existing merged tick, filters, theft/dialogue/combat safeguards and popup feed. Outfit Wheel's saved fields, lifecycle cleanup and guarded ticks remain; torch guards, FriendlyHUD listeners and movement walk toggles remain. No other concrete semantic defect was established in those merges. Two were subsequently refreshed for Steam's new vanilla changes; the other three are packaged byte-identically.

Steam also changed native code beneath seven independent mod overrides. Current native APIs and fixes were selected while retaining mod additions: inventory forceAdd and map-pin insideBounds parameters, current ladder hand IK, removed marketing APIs/current graphics controls, radial desaturation restrictions, and meditation controls feedback. FriendlyHUD crafting tracking, map zoom/filter synchronization, quick-item lifecycle, menu customization and Outfit Wheel cancel/save events remain. Torches still retains left-hand items through ladder interaction. No intentional feature loss in these seven adaptations; tests add ladder traversal, map pins/bounds, inventory rewards/crafting, radial restrictions, graphics menu and meditation feedback. Compiler/engine dispatch remains unverified.

English choices: BIA wins IDs 1092187 (sylvan naming), 1130095 (future threat), and 391138 (short ambush subtitle, avoiding potentially duplicated preceding dialogue). Grammar wins cosmetic brace spacing at 558403. ID 1063514 combines Grammar's correction/paragraphing with UPR's meaningful added sentence, repairs its typo, and restores vanilla's final signature. Sacrifices: the competing noun/tense and Grammar's expanded ambush subtitle. Verify matching speech/subtitle segmentation in game; no recorded voice comparison was available. Other languages remain untouched.

strings.list is bookkeeping, not runtime .w3strings text; retain the files without manufacturing a union. The shared Mods menu label is intentional. Arrow receives a layout correction with no gameplay-code edits. Optional F8/F9/F10/F11 shortcuts fill vacant keys only; existing assignments, including Outfit Wheel F3, remain intact. No wholesale input-settings reset.

**Revised Gwent decision: retain the complete vanilla-Gwent variant.** The earlier whole-package exclusion was too conservative: it confused a correctable installation layout and untested compiled integration with a reason to discard the mod. It also understated the feature set. Nothing was removed from the live installation.

Selected implementation: Gwent Deck Choice 2.02 (internal info version 6.0), correctly installed with its paired DLC and authored compiled scripts. Gwent My Way is absent from the audited setup, so its alternative variant is omitted. The [author documents BIA compatibility with GDC taking priority](https://www.nexusmods.com/witcher3/mods/11745). This supports a practical winner choice, not proof that every BIA node edit is incorporated. Documentation marks these two resources as Next Gen edits, but both exist in the installed Remastered bundle; actual file evidence governs the collision inventory.
