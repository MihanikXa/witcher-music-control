# Bottom-screen text and dialogue option refinement — 12 October 2026

**Authority:** Newest explicit user feedback, recorded verbatim in [HUD batch runtime feedback](../research/ink-hud-batch-v1-runtime-feedback.md). This is an intended design correction, **not** a verified new build or in-game fix.

## Two separate requests

**1. Bottom-screen ordinary text shadow.** The user says subtitles/text at the bottom still have the old, overpowering shadow and should inherit **our accepted NPC Shadow v1 optical treatment**. Goal: soften overly heavy, opaque black glows/outlines on subtitles, spoken dialogue, prior spoken lines, ambient barks and comparable lower HUD texts *when they actually use such effects*. Preserve the existing content, font identity, size, contrast, timings and layout. Treat `#141718`, alpha about `166/255`, blur about 2 and strength about 1 as a **visual target from** [shadow design](text-shadow-unification.md), not universal drop-in bytes. Verify against bright snow and black interiors. Do not blindly edit every GlowFilter or text element; distinguish ordinary text from selected-state, warnings, icons and meaningful effects.

**2. Dialogue option scale.** User likes the **style** of Ink & Iron's dialogue choices but finds the choice typography too big. Maintain font family, colors, hierarchy and layout language, but reduce option font size and proportionate vertical footprint. **Assistant initial test hypothesis**: around 15–20% smaller than current, adjusted after in-game screenshots and actual controller viewing distance. This percentage is not a direct user demand. Keep click/controller focus areas usable; if needed keep hit regions unchanged while shrinking text. Preserve active/highlighted/disabled/timed choices, choice countdowns, answer wrapping, dialogue scrolling, bargaining and controller navigation. The request **does not imply** making spoken subtitle text 15–20% smaller.
