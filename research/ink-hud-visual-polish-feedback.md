## Observations and requirements

- **Controller glyph art is visible now**, superseding the older *missing Xbox icons* issue. It looks visibly **pixelated/low-resolution, too large, poorly proportioned for Ink & Iron + QuietFolio**, and has bad spacing/baseline alignment relative to menu labels. Source screenshots show a large `A` circular Talk prompt under a Peasant name and a horizontal footer with `A Select`, `L [Hold] Description size`, `L Hide descriptions`, `LT Previous Tab`, `RT Next Tab`, `B Back`. In the footer, large outlined circles/trigger boxes intrude on text and spacing; *determine whether field or font metrics, original icon dimensions, image sampling, or GFx matrix scaling cause it*, rather than asserting it is just a color/bitmap fix. Do not simply shrink a bitmap without checking effective sharpness at gameplay and 4K resolution. Retain flat/no-gradient art, Xbox recognizability, gamepad interaction and accepted typography language.
- **Accepted geometry:** thin health bar, compact whole enemy-overhead UI, name/level/lock scale, and unmodified boss bars. Avoid touching this.
- **Ordinary hostile reds:** improved but should be a **little richer**. Current v3 candidate has `#B65348` enemy health, `#D87566` hostile name and `#C98678` lag. Check actual installed palette/overrides; deepen/richen **health and name together**, preserving their balance and non-hostile semantic categories. New RGB values are implementation experiments until user accepts them.
- **Separate attack warning / flash:** user observed overly saturated red effect during wolves combat, timing not observed conclusively. Likely **pre-attack dodge feedback**, not `iaiLag` delayed enemy-health loss. Diagnose exact active field/clip and timing, focusing on `mcDodgeFeedback`, Flash tweens and SAHUD overrides, before patching. **Explicit visual hierarchy: the warning MUST REMAIN MORE VIVID than the ordinary health bar**, but **less vivid/visually aggressive than now**. Prefer **opacity reduction** as first controlled experiment, potentially using a modest multiplier on existing animated alpha (e.g. start at 0.65–0.75 of current rendered opacity) rather than replacing the original flash color or freezing its alpha, and preserve the full attack tell timing/legibility, especially for wolf lunges. Only change hue if alpha alone cannot produce appropriate contrast. Never disable the warning or match it exactly to the base bar.
- Preserve v3/V2 runtime-working input, HUD/shadow/quickslots/dialogue function; if package currently tested cannot be established from local evidence, do not claim v3 fully visually accepted. Existing v3 offline technical checks are a starting point, not proof of high-quality rendered glyphs.
