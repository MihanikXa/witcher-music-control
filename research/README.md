# Research

Use this directory for reproducible investigation notes before and during implementation.

For each finding, record:

- exact source file/path
- class/function/symbol
- what was observed
- whether it is fact, inference, or hypothesis
- how it affects the proposed architecture
- what would falsify the conclusion
