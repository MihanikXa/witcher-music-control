# Witcher 3 Remastered mod compatibility audit

This `general-merge` branch contains the independent installed-mod audit and its
original helper scripts. The music-control project remains on `main`.

Start with [the audit review checkpoint](audit-2026-10-08/README.md).

Game assets, third-party mod payloads, private machine-state evidence and actual
installable patches remain local and are excluded from Git. No live deployment
or game launch is authorized by publishing these reports.
